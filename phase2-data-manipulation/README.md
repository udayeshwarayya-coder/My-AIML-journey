# Phase 2: Data Manipulation & Visualization (Days 31–80)

> **Goal:** Master core Python data engineering, array computation, data wrangling, and statistical visualization using **NumPy**, **Pandas**, **Matplotlib**, and **Seaborn**. Build robust analytical intuition and flexible, cumulative project milestones paired with daily algorithmic problem-solving.

---

## 📌 Phase 2 Operating Architecture

Following the updated Phase 2 guidelines:
1. **Topic-Wise Daily Flow:** Each day tackles a focused, manageable slice of a topic strictly following the AIML roadmap progression.
2. **Flexible Cumulative Projects:** Projects are no longer rigidly tied to every 4th day. Instead, they are built **flexibly at the completion of a logical topic block**, synthesizing and integrating **all previous topics** covered up to that milestone.
3. **Daily 2 LeetCode Problems:** Every day includes 2 curated LeetCode problem numbers + titles (no solutions) arranged in a natural difficulty and conceptual flow matching the day's skills.
4. **Roadmap Fidelity:** 100% adherence to all curriculum topics across NumPy, Pandas, Matplotlib, and Seaborn.
5. **Hands-On Code Ownership:** Every single line of code for projects and practice is written exclusively by the user. Concept explanations must always use completely distinct, decoupled domains and functions (never pre-solve or expose the project/practice functions).
