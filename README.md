## ?? About This Journey

This repository documents my **300-day project-based AI/ML learning journey**, starting from Python OOP all the way to deploying full-stack AI applications.

**The formula:**
- ?? Every **day** ? Learn concepts + write 3 Python logic functions
- ??? Every **4 days** ? Complete a full-stack project with Flask backend + frontend
- ?? Every project **revisits earlier concepts** (spaced repetition built-in)
- ?? End goal ? Placement-ready portfolio with **71 real projects**
