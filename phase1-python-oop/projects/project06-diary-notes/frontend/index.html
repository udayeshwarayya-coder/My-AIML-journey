⚙️ Backend API Blueprint (Flask)

This frontend is configured to communicate with your Flask backend on http://localhost:5000. When your backend is running, the badge turns green automatically!

Recommended Flask Endpoints:
GET    /api/notes       → List all notes
POST   /api/notes       → Create new note (JSON body)
PUT    /api/notes/<id> → Update note (title, content, tag, pinned)
DELETE /api/notes/<id> → Remove note
GET    /api/notes/tags → Group notes by tag (tag_notes)
GET    /api/notes/stats→ Word count & analytics (word_count)

💡 Tip: While you build the backend, all changes are safely stored in your browser's localStorage, so you can test all UI features right away.
